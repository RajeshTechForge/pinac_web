## 🚀 Getting Started

1. Clone the Repository

   ```bash
   git clone https://github.com/RajeshTechForge/pinac_web.git
   cd pinac_web

   ```

2. Install dependencies

   ```bash
   cp .env.example .env

   npm install

   ```

3. Start the App
   ```bash
   npm run dev

   ```
